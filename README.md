## 🚀 Deployment (Vercel)

This is a clean static web application:
- `index.html` (Main entry point)
- `assets/css/` (Styles and animations)
- `assets/js/` (Audio player, particle engine, image metadata)
- `assets/images/` (Original photographs & artwork)
- `assets/audio/` (Background music)
- `vercel.json` (Vercel configuration)
